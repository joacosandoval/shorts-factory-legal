Privacy Policy – Shorts Factory Metrics

Last updated: October 28, 2026

1. About this app

Shorts Factory Metrics ("the app") is a personal, single-user tool. It is used only by its developer to read performance metrics of the developer's own YouTube channel and Instagram account. The app is not offered to the public.

2. Data accessed

With the explicit consent of the account owner, the app uses the YouTube Data API and the YouTube Analytics API (read-only) to access metrics of the owner's own channel, such as views, watch time, likes, comments and subscriber changes.

3. How data is used

The data is used exclusively to generate personal performance reports for the account owner. It is not used for advertising, profiling or any other purpose.

4. Storage and security

OAuth credentials and tokens are stored locally on the developer's own computer, outside any public repository. Retrieved metrics are stored locally only. No data is uploaded to third-party servers.

5. Sharing

The app does not sell, share, transfer or disclose any data to third parties.

6. Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deleting data

Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. Locally stored data can be deleted at any moment by removing the app's local files.

8. Contact

Questions about this policy: hardsimplethings@gmail.com
